# Lockdown Practice Test

A single-page app for taking timed practice tests in a fullscreen lockdown mode.

- Upload or paste a test (.txt, .csv, .json, .pdf); intro pages, page numbers and headers are cleaned up automatically
- Answer keys (separate or embedded in the test) stay hidden until you submit
- Reference materials (formula sheets, notes) open in a side panel without breaking lockdown
- Fullscreen enforcement, tab-switch and focus-loss detection, violation log, auto-submit
- 5-minute warning, scored results with question-by-question review

Everything runs in the browser. Uploaded files never leave your computer.

Open `index.html` locally, or visit the GitHub Pages site for this repository.
